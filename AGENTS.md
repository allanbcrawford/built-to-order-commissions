This is the public commissions repo for Built to Order, a YouTube channel. Viewers file commissions as GitHub issues and vote with 👍. Everything here is public.

The process, the screening checklist, and the label meanings are in `HOW-IT-WORKS.md`. Change the form, the labels, and that file together, so they stay in step.

`SUBMISSION_TERMS.md` is a legal draft. Do not change its meaning without Allan's say-so.

Each `bto-<name>/` folder here is a separate build repo, ignored by this one. Run `git` from inside the repo you are changing.

Use the terms in the home repo's `GLOSSARY.md` (`../GLOSSARY.md`). Say "commission", not "idea".
